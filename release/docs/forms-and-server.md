# فرم‌ها، سرور و پرفورمنس

## فرم‌های نمایشی

فرم‌های صفحه‌ی اصلی، صفحه‌ی تماس، بسته‌های همکاری و خبرنامه **به هیچ سرویسی متصل نیستند**.
اعتبارسنجی در مرورگر انجام می‌شود و پس از ارسال، پیامی نمایش داده می‌شود که اطلاعاتی ارسال
نشده است.

برای فعال‌سازی، یکی از این راه‌ها را انتخاب کنید:

1. **سرویس فرم آماده** (Formspree، Basin و مشابه): مقدار `action` را روی فرم بگذارید،
   `method="post"` را اضافه کنید و `<form ... data-demo-form novalidate>` تبدیل به
   `<form class="mt-6" action="…" method="post">` کنید. سپس بلوک ارسال در `main.js`
   را حذف کنید (تابع `initForms`) یا `data-demo-form` را بردارید.
2. **اندپوینت سروری خودتان**: یک مسیر POST بسازید و `action` را به آن بدهید.
3. **سرویس ایمیل تراکنشی**: از سمت سرور، درخواست را به API سرویس ایمیل بفرستید و کلید را
   هرگز در HTML یا JS مرورگر قرار ندهید.

پس از اتصال، متن «این فرم نمایشی است» را از صفحه‌ی تماس و فوتر حذف کنید و صفحه‌ی تشکر
(با `noindex`) بسازید.

## نکات سرور

- فشرده‌سازی Brotli یا gzip را فعال کنید.
- برای فایل‌های نسخه‌دار (CSS/JS/تصاویر) هدر `Cache-Control: public, max-age=31536000, immutable`
  بگذارید؛ برای HTML مقدار کوتاه‌تر.
- صفحه‌ی `404.html` را به‌عنوان سند خطای ۴۰۴ تعریف کنید.
- از HTTP/2 یا HTTP/3 استفاده کنید.
- اگر آدرس تمیز می‌خواهید، rewrite تعریف کنید و `canonical` و `sitemap.xml` را هم‌زمان
  به‌روز کنید.

## پرفورمنس

- هیرو با `<picture>` و AVIF/WebP ارائه می‌شود و `fetchpriority="high"` دارد.
- بقیه‌ی تصاویر `loading="lazy"` و ابعاد مشخص دارند.
- فونت‌ها سلف‌هاست، WOFF2 و با `font-display: swap`.
- هیچ اسکریپت شخص ثالث، CDN یا فونت آنلاین در قالب نیست.
- جاوااسکریپت یک فایل کوچک است و با `defer` بارگذاری می‌شود.

اعداد Lighthouse در این قالب اندازه‌گیری نشده‌اند؛ پیش از انتشار با نسخه‌ی سرو‌شده
(نه `file://`) و فشرده‌سازی فعال اندازه بگیرید. برای اندازه‌گیری معتبر، حداقل سه اجرای
موبایل را میانگین بگیرید.
