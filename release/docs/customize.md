# تغییر رنگ، فونت و بیلد

## توکن‌های طراحی

همه‌ی رنگ‌ها در `source/src/styles/main.css` داخل `@theme` تعریف شده‌اند:

```css
--color-brand: #2b6c88; /* رنگ برند */
--color-brand-700: #1b4457; /* حالت فشرده‌شدن دکمه */
--color-brand-300: #8dbcd2; /* تأکید روی پس‌زمینه‌ی تیره */
--color-ink-950: #121618; /* تیره‌ترین سطح */
--color-ink-900: #1b2023; /* بخش‌های تیره */
--color-paper: #f6f2ec; /* پس‌زمینه‌ی روشن */
--color-muted: #646c71; /* متن کم‌رنگ */
```

برای تغییر رنگ برند، فقط `--color-brand` و دو سایه‌ی آن را عوض کنید و دوباره بیلد بگیرید.
سپس کنتراست متن سفید روی رنگ جدید را بررسی کنید (حداقل ۴٫۵:۱).

## تایپوگرافی

فونت **Vazirmatn** (مجوز SIL OFL 1.1) به‌صورت سلف‌هاست در `assets/fonts/` قرار دارد.
وزن‌های ۴۰۰–۵۰۰ و ۶۰۰–۷۰۰ به‌کار رفته‌اند. اگر فونت دیگری انتخاب کردید:

1. فایل WOFF2 را در `assets/fonts/` بگذارید.
2. `@font-face` و `--font-sans` را در `main.css` به‌روز کنید.
3. `preload` را در `<head>` همه‌ی صفحات تغییر دهید.

## بیلد

```bash
cd source
npm install
npm run build     # CSS مینیفای‌شده + JS باندل‌شده
npm run dev       # سرور محلی روی 127.0.0.1:5173
```

- CSS از `src/styles/main.css` به `../assets/css/style.min.css` ساخته می‌شود.
- JS از `src/js/main.js` به `../assets/js/main.js` باندل و مینیفای می‌شود.
- پیش‌نیاز: Node.js نسخه ۲۲٫۱۲ یا بالاتر.

## کلاس‌های کامپوننت

الگوهای تکرارشده به‌جای فهرست طولانی کلاس، کامپوننت دارند:
`svc-card`، `proj-card`، `post-card`، `team-card`، `step`، `accordion`، `field`، `btn`،
`client-strip`، `stat-card` و `slider`. تعریف آن‌ها در بخش `@layer components` فایل
`main.css` است.

## اسلایدر بخش hero

هدر صفحه‌ی اصلی (`index.html`) سه اسلاید دارد؛ هر اسلاید یک `<div class="hero__slide" data-hero-slide>` با یک `<picture>` است و فقط اسلاید اول کلاس `is-active` دارد.

- برای تغییر تصاویر، فایل‌های `assets/images/hero-slide-2-*` و `hero-slide-3-*` را با تصویر خود عوض کنید (نسبت ۱۶:۹).
- برای افزودن اسلاید، یک بلوک `hero__slide` و یک دکمه‌ی `data-hero-dot` اضافه کنید؛ اسکریپت تعداد را از DOM می‌خواند.
- سرعت پخش خودکار را از `AUTOPLAY_DELAY` در `source/src/js/hero.js` تغییر دهید (پیش‌فرض ۷ ثانیه). پخش با هاور، فوکوس و تب پنهان متوقف می‌شود.
- فقط اسلاید اول با `fetchpriority="high"` و بدون `lazy` بارگذاری می‌شود تا LCP حفظ شود؛ بقیه `loading="lazy"` دارند.
- برای استفاده از ویدئو به‌جای اسلاید اول، داخل همان `hero__slide` یک `<video muted loop playsinline poster="...">` بگذارید. فایل ویدئو را خودتان تهیه کنید؛ در بسته‌ی نمونه ویدئویی وجود ندارد.

## دسترس‌پذیری

- رنگ فوکوس با `:focus-visible` تعریف شده است؛ آن را حذف نکنید.
- انیمیشن‌ها با `prefers-reduced-motion` خاموش می‌شوند.
- برای هر تصویر متن جای‌گزین معنادار بنویسید و برای تصاویر تزئینی `alt=""` بگذارید.
